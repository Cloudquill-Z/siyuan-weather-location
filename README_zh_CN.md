# 思源笔记天气与位置插件

一个思源笔记插件，通过高德地图查询天气和位置信息，并通过模板插入到笔记中。

## 功能特点

- 🌤 **天气查询**: 通过高德地图 API 获取实时天气预报数据
- 📍 **位置查询**: 通过浏览器定位 + 高德逆地理编码获取精确地址
- 📝 **可视化格式**: 字段标签点击/拖拽组合，符号自由输入，无需手写模板语法
- ⚡ **斜杠命令**: 输入 `/tq` 或 `/天气位置` 快速插入；常用城市有独立快捷指令
- ⭐ **常用城市**: 最多保存 5 个城市，支持拼音首字母快捷查询

## 安装方法

1. 从思源笔记集市下载插件（设置 → 集市 → 插件）
2. 在 设置 → 集市 → 插件 中启用插件

## 配置说明

### 高德地图 Key

插件使用高德地图提供天气和位置服务，只需一个 Key。

1. 访问 [lbs.amap.com](https://lbs.amap.com/) 注册账号并创建应用
2. 获取 Web 服务 API Key
3. 在插件设置中输入该 Key

### 位置获取

插件通过浏览器定位获取当前坐标，再调用高德逆地理编码 API 解析详细地址（省份、城市、区县、街道等）。浏览器会提示授予位置权限。

### 常用城市设置

插件支持保存最多 5 个常用城市，每个城市会自动生成拼音首字母快捷指令。

- **搜索添加**: 通过高德地图搜索城市名称，从结果中选择
- **手动录入**: 直接输入城市名称、纬度和经度
- **自定义前缀**: 可自定义每个城市的拼音快捷指令前缀
- **编辑/删除**: 在设置面板中修改城市信息或删除已保存的城市
- **快捷指令格式**: `<前缀>tq`，如 `/bjtq` 查询北京天气

### 输出格式

插件采用可视化方式设置输出格式，无需手写模板语法：

- **字段标签**：天气、位置、时间等字段以标签形式呈现，点击标签即可加入格式，也可以把标签拖动到目标位置
- **符号文本**：标签之间的输入框可填写任意符号或文字（如 `:`、`|`、`°C`、`**加粗**` 标记），随格式原样输出
- **换行标签**：加入「换行」标签即可另起一行
- **调整顺序**：直接拖动格式区中的标签即可重新排序，标签会携带其前面的符号一起移动
- **实时预览**：格式编辑区下方实时显示输出效果
- **恢复默认**：一键恢复默认输出格式

#### 可用字段

天气：天气状况、白天天气、夜间天气、当前温度、相对湿度、风向、风力、风速、最低温度、最高温度

位置：当前位置、省份、区县、乡镇/街道、街道、门牌号、精确地址、附近地点、详细地址、国家、坐标

其他：记录时间、换行

## 使用方法

### 方式一：斜杠命令
在编辑器中输入 `/tq` 或 `/天气位置` 快速插入天气位置模板。
如果配置了常用城市，可使用快捷指令如 `/bjtq`（北京）、`/cstq`（长沙）等。

### 方式二：命令面板
- `插入天气信息`
- `插入位置信息`
- `插入天气位置模板`
- `打开天气位置设置`

### 设置面板功能
- **测试按钮**: 测试数据获取，验证 API Key 和网络连通性
- **清除缓存**: 清除缓存的天气和位置数据，下次请求将重新获取
- **恢复默认格式**: 一键恢复默认的输出格式

## 输出示例

默认格式输出效果：

```markdown
## 今日天气与位置

🌤 **天气状况**: 晴转多云
🌡 **当前温度**: 28°C
💧 **相对湿度**: 62%
🌬 **风向**: 东南风
💨 **风力**: 3级
📍 **当前位置**: 岳阳市
⏰ **记录时间**: 2026/6/12 15:30:00
```

把字段标签排成一行、符号输入框填上 ` | `，即可得到单行简洁输出：

```markdown
**天气**: 晴转多云 | **温度**: 28°C | **位置**: 岳阳市
```

## 注意事项

1. **API Key 安全**: 请妥善保管你的 API Key，不要分享给他人
2. **免费额度**: 高德天气 API 有免费调用额度，超出后可能需要付费
3. **浏览器权限**: 定位功能需要浏览器授予地理位置权限
4. **网络要求**: 插件需要网络连接才能获取天气和位置信息

## 常见问题

**Q: 为什么获取不到天气信息？**
A: 请检查：
- 高德地图 API Key 是否在设置中正确填写
- 网络连接是否正常
- 可使用设置面板中的"测试"按钮验证

**Q: 为什么位置不准确？**
A: 插件使用浏览器定位。请确认已授予位置权限，或尝试在信号更好的位置使用。

**Q: 如何添加常用城市？**
A: 打开插件设置 → 常用城市区域。可搜索城市名称或手动录入坐标。

**Q: 最多可以保存几个常用城市？**
A: 最多 5 个。

**Q: 快捷指令的含义是什么？**
A: 每个常用城市会根据城市名自动生成拼音首字母前缀。例如北京 → `bj`，快捷指令为 `/bjtq`（bj + 天气）。你可以在设置中自定义前缀。

**Q: 如何清除缓存数据？**
A: 在设置面板中点击"清除缓存"按钮。下次请求时将重新获取最新的天气和位置数据。
